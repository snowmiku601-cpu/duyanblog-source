# Playbooks

Task-scoped procedures. Nothing here auto-loads — `CLAUDE.md` links the ones a task needs.
A playbook is the answer to "how do we do X again"; a rule is "what may we never break".
If a playbook's procedure becomes invariant it graduates to `.claude/rules/`; if it becomes
history it retires to `.claude/archive/`.
